# Tube v2.2.2: automatic release build

**Tube 2.2.2** is the same app as 2.2.1. It is the first version built and published by the release workflow on its own: every push to the `tube` branch now runs the tests, and a new version number gets a signed APK on this page without a manual build.

**Changed**
- Nothing in the app. The miniplayer and Shorts fixes from [2.2.1](https://github.com/NitinReddy-A/bopbox/releases/tag/v2.2.1-tube) are all here.

**Verified:** the workflow ran the 108 JS unit tests, typecheck and lint before building this APK; the 142 Kotlin unit tests pass locally on the same code.
