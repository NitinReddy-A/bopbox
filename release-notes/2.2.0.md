# Tube v2.2.0: miniplayer, app gestures, faster starts

**Tube 2.2.0**: the touch behaviour of the YouTube app, and less work standing between a tap and the video.

**What's new**
- **Miniplayer.** Drag a video down, or press back while it plays, and it shrinks into a floating player while you keep browsing. Tap it to expand, drag it to another corner, fling it sideways or tap × to close. Back on a paused video simply goes back.
- **App gestures.** Swipe the player up for fullscreen, press and hold for 2× speed, double tap a Short to like it (with a heart and a haptic).
- **Replay.** Shorts always loop. Videos replay when they end; "Always repeat" is now on by default (updating switches it on once). Turn it off in Settings if you want autoplay and playlists to move on.

**Faster**
- Video stream, thumbnail and avatar requests no longer go through the ad-filter engine (no list can block them there; ads are stripped from the player response instead).
- Ad rules only parse a response when its text can contain an ad, so most watch and browse responses reach YouTube untouched.
- One timer instead of eight, asleep while Tube is in the background.
- On slow or metered connections the start quality is capped so the first frame is not held up; on good connections videos still start at 1080p.
- YouTube starts loading before the app's own UI mounts.

**Settings:** a Miniplayer switch (Player section).

**Verified:** 102 JS and 141 Kotlin unit tests, and 66 gesture checks in real Chromium with touch input against a stand-in for YouTube's mobile page. Not yet run against YouTube itself or on a phone: if a gesture misbehaves, switch Miniplayer off in Settings and please report it.
